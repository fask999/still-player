# STILL · 玻璃静室

本轮界面由 Astra 按用户参考与实际工作区重排。专辑库为可直接进入的封面网格；听音页保留左侧导航、中央封面矩阵、右侧歌词或当前播放列表。内容来自真实播放器、已读播放上下文和歌词服务。

## 听音与当前播放列表

- 点专辑封面进入专辑；播放仍由明确动作发起。
- 中心封面、歌名、背景、歌词和进度只随实际播放器读回更新。左右卡片展示真实当前播放列表中 currentIndex 前后的 occurrence，重复曲目保持各自位置；这不声称知道随机播放时后端下一次会选哪首。
- 当前列表完整且真实当前 occurrence 匹配时可展示邻项。后端未确认顺序可预测时，邻卡只读；已验证可操作的近邻才可发原生上一首或下一首。远邻只展示。未知或过期上下文清空，不能拿资料库或本地临时队列冒充 Apple 列表。
- 左右拖动封面与底栏上一首、下一首均走真实后端控制，中心内容等待读回。垂直滚动、取消、来源或 occurrence 改变会撤销旧手势，不重建专辑或资料库播放队列。
- 右侧“当前播放列表”只读，暂不提供行选播或队列编辑。既有“本地临时队列”保留独立语义。
- 底栏只有曲目信息、上一首/播放/下一首、唯一可拖动进度轨道和音量。播放模式、歌词设置/搜索/导入、临时队列及本地输出设备统一放在左侧齿轮“音频与设置”。

## 封面原色、主题色与背景

“音频与设置”内的“光线与外观”提供“封面原色”和“主题色”，并保留预设与六位 hex。appearance.accentMode 与 accentColor 一次原子保存；默认兼容原有主题色偏好，切换原色不删除已选颜色。预览、串行保存、失败回滚和较新返回保护同时覆盖这两个字段，不覆盖歌词或其他设置。

主题色模式仅在显示层给封面着色；原色模式恢复封面原有颜色并使用中性强调。下载或嵌入原图字节始终不变。正在播放封面的淡化版本成为背景：新图解码完成后双层交叉渐变，快切旧响应不能回写；同图不重复淡变。首次同 URL 失败后，普通轮询不反复请求，明确刷新可清除失败状态并重试。

缺图或空态使用内置山水备用素材：[moonlit-lake-v1.png](../src/renderer/assets/moonlit-lake-v1.png)。生成 prompt、工具和保存路径见 [来源记录](../review-evidence/apple-playback-polish-20261101/astra-background-provenance.txt)。该图不含界面或播放数据，不能作为应用截图。

## 真实频谱、歌词与适配

在经核验数据可用时，底部进度轨道叠加本地 foobar SDK 可视化流的实际 PCM 频谱。48 个对数频带以固定 −100 至 0 dBFS 显示高度，不把每帧峰值拉满。分析采样率只代表所分析 PCM，不能作为 DAC 实际输入格式。Apple 没有受支持的分析数据时、暂停、停止、后台隐藏、切源、待命或数据过期时立即回到静态可拖动轨道，不显示装饰假频谱。该分析不采集系统音频、不改变音频输出；边界见 [频谱说明](audio-spectrum.md)。

封面透视、背景渐变和歌词跟随遵守应用/系统减少动效偏好。歌词逐行或逐词使用来源实际时间轴，不分配虚构词时间。手动滚动、暂停和恢复跟随保留各自状态。

真实诊断工作区为 **1173 × 601 CSS px、DPR 3.25**。Astra 静态预算与严格 DOM/交互回归同时覆盖该工作区、参考构图和竖屏目标；600 × 1000、1080 × 1920、1440 × 2560 与常见缩放仍须用户实际显示器体验。不能把 CSS 宽高测试当作原生 Windows、字体、可点区域或副屏 DPI 验收。

## 自动歌词与封面

手动绑定/导入、本地侧车和与当前元数据一致的缓存优先；缺失时按现有偏好自动联网。LRCLIB 有限恢复失败后，QQ 普通 LRC 备用只接受曲名、歌手、专辑、时长严格匹配且唯一的结果。line/plain/word、纯音乐、无结果和网络错误分开；不承诺所有中文歌曲、不同版本或逐词数据可用。Apple 使用真实公开元数据的泛歌词服务，不读取账号或受保护歌词。

Apple 公开封面通过受限本地协议自动下载缓存，保留域/路径、MIME/魔数/像素、体积、超时、并发和取消检查。失败 no-store，同一稳定 URL 可刷新恢复。已有本地封面优先；已索引 MusicBrainz release ID 可尝试固定 CAA 地址，未知 ID 不猜图，不默认启动未配置的 MusicBrainz 搜索。iTunes Search 自动图源未启用。

已完成的受控联网样本：汪苏泷《黑色蝴蝶》主源实际 HTTP 502 后，QQ 公开检索/LRC 成功，生产解析得到 81 行、0 词时间戳，并在独立临时状态落盘后由新服务断网读取相同时间轴。Apple 官方示例图已真实落盘、离线同 SHA；CAA 实图链超时，不能称已成功。测试缓存没有覆盖用户 data。这些证据不代表全库或实际 Apple 订阅播放通过。

用户已在 STILL 官方窗口登录并读到真实曲库，但第一包 b88 的实际 Apple 播放失败。单次复现先被本地共享释放探针 `0x887C001A` 阻断；该码仍属未知，不能称设备可用或据此诊断硬件故障。本热修的受控专属 WASAPI 退出证明、冷恢复、最新播放意图及临时 Autoplay 配置均属工程修复，实际 Apple 出声、受保护全曲、跨引擎交接和硬件零瞬音仍待用户手动复验。

Apple 页“音频与设置”→“偏好与数据”→“保存诊断状态”使用 Apple-only scope；保存到本包 `data/diagnostics/still-diagnostics-*.json`。它读取既有 Apple 服务的高层公开状态，加上缓存的本地交接证据与构建身份，不运行本地音频探针。保留固定 SDK 方法支持、错误阶段、有限操作历史、临时权限配置/seen/决策及歌曲业务 ID，不导出原页面、URL 查询、凭据、Cookie、token、认证存储或截图。
