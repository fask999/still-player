# STILL 第二版界面

这一版从“唱片陈列”和“专注听音”出发。真实专辑封面占据首屏；浏览时使用一条来源栏和顶部分类，歌词则以宽正文和右侧唱片构成独立的听音视图。

## 结构与使用

- 最左只保留本地 / Apple Music 来源入口，以及队列、设置工具。顶部为唱片、曲目、艺术家、播放列表与搜索；原来的第二条侧栏已移除。
- 无已保存偏好时打开专辑墙。已有 `settings.appearance.localView` 则恢复该页面；只有明确点击本地分类且主进程返回 `capabilities.persistUIState: true` 才保存偏好。只读 smoke 不写设置。
- 专辑封面、标题、艺术家和首数均来自真实库。已知且有封面的专辑优先，无封面次之，未归类专辑最后。没有制造推荐、收听历史、收藏统计或播放状态。
- 进入专辑、艺术家或列表详情只改变浏览。左侧唱片信息与右侧曲目并列；只有明确点击播放按钮或曲目才发送原有 IPC 播放命令。
- 歌词视图将正文置左、封面置右，收起顶部浏览导航。窄窗将封面与曲目信息收为歌词上方的小块。底部来源、状态、进度、音量、顺序始终跟随真实 player。
- 正文、译文与次级文字提高对比，低饱和琥珀仅用于当前句、进度和少量交互。封面保持原始色彩，不叠加玻璃、霓虹或旋转唱片。
- 底栏与听音页之间的真实封面有 340 ms 连续过渡，唱片与歌词有短入场动画。动画只影响绘制，不延迟状态或 IPC；快速切换会取消旧动画，用户或操作系统的减少动效偏好均优先。进度、音量仍显示为细线，指针/触屏命中区域扩大到 24 px。

## 实现边界

`styles.css` 保留控件基础样式，`room.css` 定义第二版空间结构和响应式比例。所有现有 DOM ID、来源与导航 data 属性保留。播放继续由 `window.still` 的 IPC 实现；没有 renderer 音频引擎。

原有播放请求代际、播放器 generation/revision、来源切换、队列与列表 occurrence 校验、歌词 track/revision 隔离保留。逐词、逐行、纯文本、可靠时间戳双语、无时间轴完整译文、字号行距、偏移、暂停冻结、手动滚动回当前、候选搜索/预览/绑定、原生导入、缓存与错误状态均保留。

Apple Music 仍只依据实际 capabilities 开放能力。官方会话不展示 Cider 购买或开发者付费配置；授权、曲库与播放可用性均由主进程的实际描述符决定，视觉层不会改写未登录状态或制造能力。

测试歌词在底栏与听音页均保留“测试歌词 / 非真实匹配”标记。它不是实际播放或真实匹配证据。
