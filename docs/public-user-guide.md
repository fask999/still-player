# STILL 用户指南

STILL 是独立项目，将本地音乐库、歌词和 Apple Music 官方网页会话放在同一个桌面界面中；它并非 foobar2000 官方产品，也未获得其作者背书。本指南介绍 Windows 安装、日常使用、音频输出和常见问题。

## 安装与首次打开

1. 在 Windows 10 或更新版本的 x64 系统上，确认已安装 .NET Framework 4.8 或更新版本。前往 [v1.1.0 Releases 页面](https://github.com/fask999/still-player/releases/tag/v1.1.0)，下载 `STILL-1.1.0-Setup-x64.exe` 并运行，按提示完成安装。安装时可选择程序目录；安装和日常使用无需自行安装 Node.js 或开发 SDK。
2. 打开 STILL。首次运行时，STILL 将使用随包提供的未修改官方 foobar2000 安装文件，在 `%LOCALAPPDATA%\STILL` 下自动准备独立的播放内核、Beefweb 与频谱组件。界面会显示准备进度；可选择 **稍后设置**，或在准备未完成时选择 **重试自动准备**。无需预装 foobar2000，也无需选择已有的安装或资料目录。
3. 内核准备完成后，打开左下角 **音频与设置**，在 **本地音乐输出设备** 中明确选择带设备名称的具体共享输出。不要选择 `Default` 或“主声音驱动程序”之类的模糊选项，它们无法提供切换来源时所需的精确设备释放依据。完成此步骤后再播放本地音乐或 Apple Music。

程序默认安装到当前用户的 `%LOCALAPPDATA%\Programs\STILL`，也可在安装时选择其他可写目录；安装器不请求管理员权限。无论程序放在哪里，库、设置和独立内核仍位于当前用户的 `%LOCALAPPDATA%\STILL`（通常位于系统盘）。当前安装程序未签名，Windows 可能显示未知发布者；发行附件中的 SHA-256 可用于核对下载文件，但不能代替发布者签名。

STILL 管理自己的独立播放内核，无需已有 foobar2000 安装；已有安装和播放列表无需被替换。Apple Music 官方会话额外需要系统中的 Microsoft Edge WebView2 Runtime、网络以及可用的 Apple 账户和订阅。随包的 WebView2 SDK 文件不等于浏览器运行时；如系统提示缺少 Runtime，可从 [Microsoft 官方页面](https://developer.microsoft.com/microsoft-edge/webview2/) 安装后重试。

## 本地音乐

点击左侧 **本地**，选择 **导入文件** 或 **导入文件夹**。导入文件夹会索引所选目录中的音乐；添加新文件后可使用右上角的刷新按钮。导入只记录索引和读取音乐信息，不会删除原文件。移动或移除原文件后，重新导入或刷新可帮助更新显示。

导入 CUE 时，可选择 **导入文件** 并选中 `.cue` 文件；将其引用的音频文件放在同一目录中。STILL 核验可用曲目后建立索引，不修改原 CUE 或音频。播放时会保留对相关文件的只读锁：每次内核会话最多保留 8 组，达到上限时请正常退出 STILL 后重新打开。若 CUE 或引用的音频需要更改，先正常退出以释放锁；更改后重开 STILL，刷新或重新导入再播放。

顶部可在 **唱片**、**曲目**、**艺术家** 和 **播放列表**之间切换，也可按曲名、专辑或艺术家搜索。打开专辑或列表，选择曲目开始播放。播放列表用于保存收藏；曲目菜单中的 **加入本地临时队列** 用于安排接下来播放的曲目，二者互相独立。导入的格式是否能够播放还取决于内核和解码组件。

## 听音与歌词

点击底部的封面或曲名，进入听音界面。右侧可切换 **歌词** 和 **当前播放列表**；点击 **返回音乐库** 回到浏览界面。歌词有时间信息时可以跟随播放；没有时间戳的纯文本只显示文字，不会自动逐句高亮。

从左下角 **音频与设置** 进入 **歌词设置**，可调整显示和时间、控制在线查找与缓存。也可在该处搜索或导入歌词。在线结果可能没有匹配版本；手动导入或选择适合当前曲目的歌词可以解决版本不符的问题。

歌词设置可分别控制原文与译文、字号和行距。可用时也会读取音频内嵌歌词；多个不同的内嵌版本无法可靠选择时，可手动导入。听音页歌词上方的 **-100 ms**、**+100 ms** 和 **重置** 可实时调整当前曲目的时间偏移；正值让歌词稍晚出现。纯文本没有时间戳，不会生成同步效果。

## 封面

音频内嵌封面优先；没有内嵌封面时，可在音频同目录放置 `cover`、`folder`、`front` 或 `album` 命名的 JPG、PNG、WebP 或 GIF 图片。STILL 会为封面准备适合列表和大图显示的缓存；允许在线查找时，仅在没有本地封面时尝试，结果取决于可用信息和网络。更改同目录图片后可刷新音乐库。

## Apple Music

点击左侧 **Apple**，按照界面提示打开 Apple Music 官方会话并自行登录。登录和浏览可在本地内核准备前进行；播放前仍须完成上面的独立内核准备，并在音频设置中选定带设备名称的具体共享输出。登录后，STILL 根据官方会话实际提供的能力显示曲库、搜索和播放控件；某些内容可能因订阅、地区、浏览器环境或服务状态而不可用。该功能依赖官方网页及其能力，STILL 不提供 Apple Music 订阅。

本版 Apple 的输出经过 Windows 系统音频路径。要使用 USB 设备，请在 Windows 的声音设置中为网页会话选择该设备。本地音乐输出选择不会更改 Apple 的设备。本版尚未提供 Apple 播放流的应用内精确设备选择或可验证的 WASAPI 独占，也不承诺自动 DAC 采样率切换。

## 本地输出和 USB 设备

本地播放默认使用系统共享输出。先打开左下角 **音频与设置**，在 **本地音乐输出设备** 中明确选择带设备名称的具体共享输出，不要选择模糊的 `Default` 或“主声音驱动程序”。若设备列出 WASAPI 独占选项，可根据当前设备格式为本地播放明确选择该选项；设备、驱动以及其他应用对设备的占用都会影响其是否可用。界面显示的是播放器读回的配置，并不测量 DAC 实际接收格式或证明设备已独占。

需要调整独占输出格式时，先停止播放并退出 STILL，再打开专属目录中的 foobar2000，在 **File → Preferences → Playback → Output** 中选择设备支持的格式与位深，正常关闭后重新打开 STILL。若设备兼容，32-bit 可作为尝试选项；这不是对音源位深或实际音质的保证。请依据自己的设备设置，不要照搬其他设备的格式或音量偏好。

USB 设备断开或重连后，检查设备状态，并按界面提示明确重试连接或重新选择播放。STILL 不会将重新连接视作自动恢复播放的证明。设备不可用时也可先检查 Windows 声音设置、连接和驱动。

### USB DAC 授权

在 **音频与设置** 中选中当前连接的 USB 音频设备，可审阅需要授权的操作与验证格式，再由本人确认。授权仅用于已核验的 USB 设备和内置 WASAPI 输出，可用于所选的独占格式检查或符合条件时的专属内核交接退出；检查会尝试短暂申请并释放所选格式的音频流，结果以实际状态为准。

授权可选择两种身份范围：

- **硬件实例**：需要 Windows 提供可在系统范围内核验的唯一 USB 身份。
- **本机当前 Windows 端点**：没有可核验的稳定硬件身份时，可明确选择此范围；它绑定当前端点的 GUID 和 USB 拓扑与枚举信息。换接口或设备重新枚举后需要重新确认。此范围无法区分 Windows 本身看不出的物理设备更换。

授权有效期为 30 天，可在设置中撤销；到期、设备或内核身份变化后需重新确认。授权不会自动迁移或替你选择设备，也不会自动播放、切换采样率，或将未知的设备释放状态当作已释放。

## 桌面控制

STILL 会记住窗口位置、大小和最大化状态；显示器发生变化时会把窗口调整到可见区域。在 **音频与设置 → 桌面控制** 中，可设置 **播放时防止系统睡眠**，显示器仍可自然熄屏；也可启用 **Windows 媒体卡片和媒体键**。

在同一区域选择时长并点击 **设置定时停止**，到期后会尝试停止播放并释放音频，结果以界面状态为准；它不会让电脑睡眠或关机，定时只在本次会话内有效。也可启用全局自定义快捷键，并为播放／暂停、上一首、下一首或显示窗口保存包含 Ctrl 或 Alt 的组合键；快捷键占用时以界面状态为准。

## 外观、数据与卸载

在 **音频与设置** 中选择 **光线与外观**，可调整界面颜色；开启 **减少界面动效** 可减少动画。STILL 会缓存封面和可选的歌词，供后续显示使用。

公开安装版的数据位于 `%LOCALAPPDATA%\STILL`，包括库、设置、Apple 登录状态和专属内核，与安装时选择的程序目录无关。在 **音频与设置** 中也可点击 **打开 STILL 数据目录**。从 Windows 已安装的应用或开始菜单中的 **Uninstall STILL** 卸载；默认保留这些数据。升级时先退出 STILL、卸载旧版，再安装新版，保留的数据可继续使用。卸载时，关闭状态下符合安全检查的安装目录 `debug.log` 会以不覆盖现有文件的方式保存到数据目录的 `logs` 中；无法安全保存时，原文件会保留并提示。其他未知文件会保留。若确定不再需要数据，可在关闭 STILL 后自行备份或删除该目录。原音乐文件存放在你导入时选择的位置，卸载程序不会替你删除它们。

## 常见问题

**本地内核无法连接**：检查首次准备是否完成，按界面提示重试；也可在 **音频与设置** 中查看错误详情。

**提示路径过长或内核组件无法加载**：Windows 中异常深的数据目录或文件路径可能影响内核组件加载。通常可使用默认的 `%LOCALAPPDATA%` 数据位置，并检查所选音乐文件的路径；已有数据请先备份，不要直接移动或覆盖正在使用的目录。

**有曲目但无法播放**：确认原文件仍在原位置且设备可访问；刷新音乐库，并检查内核是否支持该格式和当前输出。对于 CUE 等容器，具体子曲目是否可播取决于内核提供的条目。

**听不到声音或 USB 设备重连后无声**：核对当前播放来源。对本地音乐，检查 STILL 的本地输出和设备状态；对 Apple Music，检查 Windows 系统输出设备及音量。确认设备没有被其他应用独占，再按界面提示重试。

**歌词缺失或不同步**：确认曲名和艺术家信息，检查在线查找设置，尝试搜索其他版本或导入本地歌词；在歌词设置中调整时间。纯文本没有时间戳，无法跟随播放逐句高亮。

**Apple Music 无法打开或播放**：先完成独立内核准备，并在音频设置中明确选择带设备名称的具体共享输出；登录或浏览成功本身不表示已满足播放条件。再检查网络、WebView2 Runtime、官方会话的登录状态、订阅和内容地区可用性。按官方页面提示完成交互，然后回到 STILL 刷新状态；功能是否可用以界面实际状态为准。

**需要报告问题**：在 **音频与设置** 中选择 **保存诊断状态**，再通过 **打开 STILL 数据目录** 找到保存的诊断文件。诊断仅在主动保存时写入；分享前请自行检查文件内容，确认适合公开或发送。STILL 的问题与反馈请提交至 [项目 Issues](https://github.com/fask999/still-player/issues)，不要作为 foobar2000 官方产品的问题提交。
